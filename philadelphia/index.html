About this map and your privacy

Privacy: This page has no backend, no analytics, and no cookies, and nothing you type is stored by crashmaps. Loading it fetches fonts from Google Fonts, scripts from cdnjs (Cloudflare) and map tiles from CARTO, and each of those services sees your IP address. An address you search is sent to OpenStreetMap Nominatim, and commute start and end points are sent to the public OSRM routing server. Those requests are subject to each service’s privacy policy.

14 — Methodology

How I Built This

PennDOT crash records are queried from the ArcGIS FeatureServer for Philadelphia County (code 67). This dataset includes reportable crashes (involving injury, fatality, or vehicle tow). Records are geocoded with WGS84 coordinates. Areas assigned by coordinate boundaries. 5,507 records processed for 2025. PennDOT’s 2021–2025 crash release no longer flags some non-motorists in “hit pedestrian” crashes as pedestrians, so pedestrian counts here run about 11% below PennDOT’s earlier 2020–2024 release for the same years.
